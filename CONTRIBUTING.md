
# Contributing to Open Decision Ledger

Thank you for your interest in contributing.

We welcome developers, researchers, AI practitioners and decision intelligence professionals.

## How to contribute

1. Explore existing GitHub issues.
2. Identify an improvement or propose a new feature.
3. Discuss substantial changes before implementation.
4. Fork the repository.
5. Create a feature branch.
6. Add tests for code changes.
7. Submit a pull request with a clear explanation.

## Contribution Areas

- Python development
- Decision evaluation algorithms
- JSON schemas
- AI explainability
- Governance and auditability
- API integrations
- Documentation
- Testing and security

## Pull Request Standards

Every pull request should include:

- Problem being addressed
- Proposed solution
- Implementation details
- Tests performed
- Documentation updates where necessary

All contributions must be original and compatible with the project's licence.

We appreciate every meaningful contribution.
